> [!NOTE]

# Usage

## Installation 
You can install Mraphics from crates.io:
```toml
[dependencies]
mraphics = "0.0.2"
```

Alternatively, you can install from the latest git commit:
```toml
[dependencies]
mraphics = { git = "https://github.com/SeiyaCooper/Mraphics" }
```

## Example
Check out the [examples directory](https://github.com/SeiyaCooper/Mraphics/tree/main/examples) for usage examples.
